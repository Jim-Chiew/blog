#kasm #docker #containerization
Kasm is a self hosted workspace streaming platform that allows you to run services like browsers, applications, and even operating systems in a container where you can access it in your browser.
# Kasm installation
Its as simple as running the commands below.
```bash
cd /tmp
curl -O https://kasm-static-content.s3.amazonaws.com/kasm_release_1.16.1.98d6fa.tar.gz
tar -xf kasm_release_1.16.1.98d6fa.tar.gz
sudo bash kasm_release/install.sh
```
